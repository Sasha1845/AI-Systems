# Докази реального використання

Сюди кладіть файли, які підтверджують, що рішення використовувалось у реальному житті, а не лише в демо.

| Файл | Звідки береться |
|---|---|
| `usage_log.jsonl` | створюється автоматично при кожному питанні в `app.py` або `ask.py` (час, питання, джерела, секунди, токени) |
| `eval_results_v1.json`, `eval_results_v2.json` | копії `solution/eval/results.json` після двох запусків `python eval.py` (v1 — перший промпт, v2 — після виправлення) |
| `screenshot_eval.png`, `screenshot_eval_v2.png` | таблиці результатів `eval.py` для v1 і v2 |
| `screenshot_usage_log.png` | журнал `usage_log.jsonl` у редакторі |
| `screenshot_chat_1..5.png`, `screenshot_chat_entropy0.png` | скриншоти чату з реальними питаннями і розкритим блоком «Джерела» |

Не додавайте сюди нічого, чого не було насправді.

Примітка: окремих замірів ручного пошуку («до») немає, у звіті це значення подано як оцінку.
