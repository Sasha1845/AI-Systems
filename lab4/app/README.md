# Картки з нотаток

Вебзастосунок, який перетворює навчальні нотатки на картки «питання — відповідь» для повторення. Працює повністю локально: модель запускає Ollama на вашому компʼютері, нотатки нікуди не надсилаються. Це одна HTML-сторінка з JavaScript, окремого бекенду немає.

Що вміє:

- стрімінг: відповідь моделі з'являється наживо, є індикатор очікування й кнопка «Зупинити»;
- картки можна перевертати, завантажити як JSON або як `.tsv` для імпорту в Anki;
- якщо в нотатках немає навчального змісту, модель не вигадує картки, а пояснює чому;
- якщо в нотатках явна фактична помилка, модель виправляє її в картці й попереджає;
- зрозумілі повідомлення про помилки: сервер не запущено, модель не знайдено, таймаут, некоректна відповідь, обірвана відповідь.

## Що потрібно

- [Ollama](https://ollama.com/download) (перевірено на версії 0.40.15, Windows)
- Python 3 — лише щоб віддати сторінку браузеру командою `python -m http.server`
- сучасний браузер (Chrome, Edge, Firefox)
- відеокарта з ≥ 4 ГБ VRAM або достатньо RAM: модель займає близько 3,9 ГБ памʼяті

## Встановлення й запуск

1. Завантажте модель (≈ 2,5 ГБ, один раз):

   ```
   ollama pull qwen3:4b-instruct
   ```

2. Переконайтеся, що Ollama працює (значок лами біля годинника або `ollama list` без помилок).

3. У цій теці (`lab4/app`) запустіть локальний вебсервер:

   ```
   python -m http.server 8080 --bind 127.0.0.1
   ```

4. Відкрийте в браузері **http://127.0.0.1:8080/** (саме `127.0.0.1`, а не `localhost`: у Windows `localhost` додає ≈ 2 с до кожного запиту).

5. Вставте нотатки, натисніть «Створити картки» (або `Ctrl+Enter`).

Сторінку не варто відкривати подвійним кліком як файл: браузер може заборонити запити до Ollama (CORS). Через `http.server` усе працює з коробки, бо Ollama за замовчуванням дозволяє запити з `http://127.0.0.1:*`.

### Рекомендовані налаштування сервера Ollama (необовʼязково)

Ці налаштування дали у вимірюваннях ×2,2–2,4 до пропускної здатності при 4–8 одночасних клієнтах (докладно — у звіті в ноутбуці). Для одного користувача вони не потрібні. Запустіть Ollama так (PowerShell, попередньо закрийте звичайну Ollama з трея):

```
$env:OLLAMA_NUM_PARALLEL="4"
$env:OLLAMA_FLASH_ATTENTION="1"
$env:OLLAMA_KV_CACHE_TYPE="q8_0"
ollama serve
```

## Параметри генерації й чому саме такі

| Параметр | Значення | Обґрунтування |
|---|---|---|
| `temperature` | 0,2 | Задача — відтворити факти з нотаток, а не творити. Низька температура зменшує вигадки. Не 0, щоб жадібне декодування не зациклювалось на малій моделі. |
| `max_tokens` | 700 | Обовʼязковий ліміт проти зациклення. У тестах 3–5 карток займали 100–270 токенів, тож 700 дає дворазовий запас навіть для 8 довгих карток. Найгірший випадок — ≈ 12 с генерації за 60 ток/с, а не безкінечність. |
| Контекст | 4096 токенів (стандарт Ollama для цієї відеокарти, у налаштування запиту не передаємо) | Бюджет у найгіршому випадку (≈ 2 символи на токен для української): системний промпт і приклади ≈ 900, нотатки (ліміт 3500 символів) ≈ 1750, відповідь ≤ 700, разом ≈ 3350 < 4096. Тому довші нотатки застосунок відхиляє з поясненням, а не обрізає мовчки. |
| `response_format` | `json_object` | Сервер примушує модель повертати синтаксично коректний JSON. Можна вимкнути в налаштуваннях, якщо рантайм це не підтримує. |
| Таймаут | 60 с | Генерація займає секунди; 60 с вистачає навіть коли модель щойно завантажується в памʼять або запит стоїть у черзі. |
| Міркування | немає | Використовується Instruct-версія `qwen3:4b-instruct`, яка не міркує. Thinking-версія (`qwen3:4b`) у тесті витрачала весь ліміт на міркування й не повертала JSON. |

## Як це працює

0. Перед відправкою всі різновиди апострофа (ʼ ’ ‘) замінюються на звичайний `'`: через рідкісний символ мала модель губила літери («з'єнання» замість «з'єднання»).
1. Системний промпт задає правила (формат, мова, один факт на картку, змістовні відповіді замість «так/ні», що робити з порожніми й хибними нотатками).
2. Три приклади «питання → правильна відповідь» (few-shot) показують моделі формат, випадок без змісту й випадок із хибним фактом.
3. Запит іде на `POST /v1/chat/completions` зі `stream: true`. Фрагменти відповіді показуються наживо.
4. Після завершення відповідь розбирається: підтримується об'єкт `{"cards": [...], "warning": ...}`, голий масив і JSON в обгортці ` ```json `. Дубльовані питання прибираються.

## Помилки й що робити

| Повідомлення | Причина | Рішення |
|---|---|---|
| «Не вдалося підключитися…» | Ollama не запущена або неправильна адреса | Запустіть Ollama, перевірте адресу в «Налаштуваннях» |
| «Модель … не знайдено» | Модель не завантажена | `ollama pull qwen3:4b-instruct` |
| «Модель не відповіла за N с» | Таймаут | Повторіть або збільште таймаут у налаштуваннях |
| «Модель повернула відповідь у неправильному форматі» | Модель не дотримала JSON | Повторіть; сирий текст відповіді видно в розділі «Відповідь моделі» |
| «Відповідь обірвано через ліміт токенів» | Досягнуто `max_tokens` | Менше нотаток або карток, або більший ліміт |
| «Нотаток забагато» | Понад 3500 символів | Розбийте нотатки на частини |

## Обмеження

- Модель на 4 мільярди параметрів помиляється: перевіряйте картки перед вивченням. У тестах траплялись вигадані терміни та зайві картки-дублікати.
- Якщо нотатки містять кілька хибних фактів, модель може виправити не всі.
- Мова карток — українська.
